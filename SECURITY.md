# Security

This repository is a CAD benchmark workspace and does not run a hosted production service.

## Reporting

Please report security concerns through GitHub private vulnerability reporting if it is enabled for the repository. If it is not enabled, open a minimal issue that avoids publishing exploit details and ask for a private contact path.

## Scope

Relevant concerns include unsafe scripts, dependency issues, or documentation that encourages unsafe credential handling. CAD model quality, manufacturing safety, structural strength, and furniture installation safety are outside this repository's security scope and must be validated separately.
